# Original design files — upload checklist

The repository now contains **14 curated project photographs and screenshots** under [`images/`](../images/); see the [captioned gallery](gallery.md). The original Proteus project is now available: **[over.and.under.voltage.device.pdsprj](../over.and.under.voltage.device.pdsprj)** in the repository root. The archive includes `ROOT.DSN` (schematic) and `ROOT.LYT` (PCB layout), so others can inspect the editable design in a compatible Proteus installation. The written documentation is based on the supplied graduation report.

## Schematic and circuit simulation

The native project file is already uploaded in the repository root. Additional optional exports may be added to `schematic/` and `simulation/`:
- Proteus project file(s)
- Exported complete schematic (.png / .pdf)
- Simulation screenshots or data

## PCB design and production

Upload to `pcb/` and `manufacturing/`:
- Proteus ARES PCB design
- PCB layout and 3D preview images
- Gerbers and drill files (where available)
- Photos of etching, CNC board, and soldering

## 3D enclosure

Upload to `enclosure/`:
- Shapr3D project or neutral export (.step)
- Model screenshots and finished assembly images

## Report and publication checks

Upload a **redacted** report copy to `documentation/` only after removing student IDs, personal contact details and any signatures or other information not intended for public sharing. Confirm collaborator consent and any university sharing restrictions first.
