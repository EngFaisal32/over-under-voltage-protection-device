The owner supplied **`routing2.pdsprj`**, a Proteus project archive. Its ZIP structure was inspected and confirmed to contain:

| Internal file | Purpose |
| --- | --- |
| `ROOT.DSN` | Proteus ISIS circuit schematic |
| `ROOT.LYT` | PCB layout |
| `PROJECT.XML` | Project metadata |
| `ROOT.CDB`, `GRAPHS.DAT`, `SCRIPTS/PWRRAILS.DAT` | Auxiliary Proteus project files |

**Upload location:** `proteus/routing2.pdsprj`

The project is a binary archive and must be uploaded unchanged; copying it into a Markdown text field will corrupt it. Once uploaded, it can be opened in a compatible Proteus installation.
